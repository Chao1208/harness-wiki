结论先行：收敛出两个选题

本轮综合的总判断：五个方向的"宽表述空白"在过去 12–18 个月内已全部被相邻工作填掉或收窄（这是 change-002 深挖最重要的止损发现），但每份底稿都核实出了收窄后仍然真实、可辩护的空白。按"空白真实性 × 数据可行性 × 与库内证据链的咬合度"收敛，五方向归并为两个选题：A5、C6、D1 三个基准型方向合并为一个三 track 统一基准（选题一）；B1 独立成题（选题二）；B3 不立项、降级留树。

选题一 · 主选LiveRepoMem（工作名）：演化仓库上的 harness 原生记忆与持续学习基准（A5 + C6 + D1 合并）

一句话定位：第一个把 harness 原生记忆机制（分层记忆文件、放置决策、compaction 存活、离线固结）当作受控变量，在去污染的真实仓库演化任务流上，同时度量"学习收益、机制质量、更新回归、漂移危害"四个截面的可执行基准。

目标 venue：NeurIPS 2027 Datasets & Benchmarks（主投）；ICLR 2028 备选；2026 Q4 以 workshop 短文 / 预注册占位。

选题二 · 副选HarnessAblate（工作名）：harness 可编辑面的前瞻消融——收益/风险双轴下的最小充分集（B1 独立成题）

一句话定位：第一个在同一 coding harness 上、固定进化算法与预算，对六类可编辑面（system prompt / 记忆 / skills / 工具 / workflow / 代码本体）做"开放哪个面进化"的前瞻性交叉消融，并同时量化收益与风险（回归率、安全衰减、膨胀、可逆性）的受控实验研究。

目标 venue：ICML 2027（主投，实验周期短、窗口紧迫故取最近截稿）；NeurIPS 2027 主会备选。

未入选：B3（弱评估器下的自进化）不立项——权重层已红海（三个月内 5 篇共进化 rubric 工作），harness 层交集空白虽真实但窗口仅 3–6 个月且"评估循环"是本质困难；降级为 medium 留树，其三角审计协议与信号可靠性思想被两个入选选题作为评测协议成分吸收（详见 第 5 节）。

二、合并与取舍论证

2.1 为什么 A5 + C6 + D1 必须合并（而非各自成篇或两两组合）

这不是 synthesis 阶段的外部撮合,而是三份底稿各自独立推导出的同一结论:deep_C6 §3.3 明确建议"不再单独立项 C-6,与 A-5 合并",并补充"D-1 是同一基准的第三个截面";deep_D1 §5 给出两个选项后倾向"(a) 合并成一篇——更强、更完整,推荐";deep_A5 的基准草案（HarnessMemBench）已经内含 FT/BWT 等 lifelong 指标与固结/干扰维度,与 C6/D1 的核心度量天然重叠。合并的实质理由有四:

  1. 数据基座完全同构,分开做是三倍重复成本。三者都需要"同一真实仓库上的时序任务序列 + 显式会话边界 + git 版本化的持久记忆目录"。仓库策展、REPOLAUNCH 级环境构建、标注管线做一次即可支撑三个 track;分开做则互相竞争新颖性且各自单薄。
  2. 指标天然分层:机制层是结果层的归因层,回归层是两者的守护层。Lifelong 曲线差(C6)时,需要 Memory track(A5)回答"是记忆没写对还是写对了没用上";记忆在更新(D1)时,需要 retention 协议回答"这次固结/compaction 破坏了什么"。三截面拼合才构成完整因果链——这正是 2026 年评审趋势偏好的"多截面统一协议"型工作(Harness the Memory、EvoMemBench 均为此型)。
  3. 竞品格局逼迫合并。单做 C6 撞 SWE-Bench-CL/SWE-Milestone/SWE-ContextBench;单做 A5 撞 DreamBench-SWE/MemTrace-Bench/LongMemEval-V2;单做 D1 撞 HCL 后续。合取后的四要素组合(deep_C6 §3.2 缺口矩阵:每一列都有人做到,没有一行全绿)是唯一无人占据的位置,且护城河随合并加深——竞争者要抢跑必须同时复制三条能力线。
  4. D1 并入不损其独立贡献,反而借壳落地。D1 的核心创新(更新反推探针、统计功效分析、守护机制横评)作为基准的 Retention track 完整保留;"没有完整任务流"这一 D1 独立成篇的最大软肋被 C6 的序列骨架直接补上。
合并的代价与对策(scope 风险)。三 track 合并后 scope 明显变大,这是本选题最大的执行风险。对策采用 deep_C6 提出的分层发布:core/lite 版(2–3 仓库、3 个记忆配置、三 track 各出最小指标集)在 2026 Q4 以 workshop 短文/预注册先行占位;full 版随月度滚动数据扩展,投 NeurIPS 2027 D&B。SWE-bench-Live 的"冻结 split + 滚动 split"模式直接照抄。若执行中 Retention track 工程量失控,降级预案是将其缩为"每序列周期性重评历史成功集"的单一协议(保留 URR 指标),完整守护横评拆去后续论文。

2.2 为什么 B1 独立成题(而不并入选题一或放弃)

  1. 研究对象正交。选题一的被测对象是记忆内容在固定 harness 机制下的读写与演化;B1 的被测对象是可编辑面本身——进化算法被允许改动 harness 的哪个部件。前者是"用 harness"的科学,后者是"改 harness"的科学。硬并会使受控变量矩阵爆炸(记忆配置 × 可编辑面 × 更新算子),任何一维都测不深。
  2. 论文类型不同,风险对冲。选题一是 D&B 型(数据+协议+榜单),周期长、护城河深;B1 是受控实验型(9 条件 × 3+ seeds,3–4 周跑完),周期短、结论快。两题并行恰好形成"快慢双轨":B1 可赶 ICML 2027(2027-01 截稿),选题一从容准备 NeurIPS 2027 D&B(2027-05 截稿)。
  3. 证据链互喂而不互斥。B1 的风险轴(回归率、可逆性)直接复用选题一 Retention track 的判定协议;B1 关于"记忆面开放进化的收益/风险比"的结论,反过来为选题一的记忆配置选择提供先验。两篇论文互引成链,构成本 wiki 项目在"harness 持续学习"上的系列辨识度。
  4. 空白同样可辩护。deep_B1 核实:现有证据全部是单面(CODESKILL/ACE)、事后换入(AHE Table 3)、观察性(Ben Sghaier)或只测收益不测风险;综述(arXiv:2608.03392)明确把"缺隔离消融、harness 膨胀、可逆性"列为开放问题。"首个跨面、双轴、预算受控的前瞻消融"表述经得起 related work 拷问。

2.3 为什么 B3 不立项

三条理由,均来自 deep_B3 自己的核实:(1) 红海——"几乎空白"已被证伪,权重层五条路线成熟,2026 年 5–7 月三个月内 5 篇评估器共进化工作密集撞车;(2) 剩余真空窄且守不住——harness 层 × 真不可验证域的交集虽空,但 TTHE/AHE/HOTE 三个作者组都在一步之遥,底稿自估窗口仅 3–6 个月,短于任何一篇像样论文的执行周期;(3) 本质困难——"进化是否真的变好"的评估循环已被理论证明是有限评估下的结构均衡(reward hacking as equilibrium),草案 C 的三角审计只能缓解不能解决,以此为主贡献的论文姿态只能是"给出经验边界",上限受制。deep_B3 建议的最稳妥切入(草案 C 审计协议)本质是评测协议而非方法——这一价值我们不丢弃:三角审计的"冻结外部锚 + canary 可验证任务 + 时间滞后审计"直接吸收进选题一的防污染与防刷榜协议(§3.4),信号可靠性思想吸收进选题二的编辑接受函数设计。处置详见第 5 节。

三、选题一立项论证:LiveRepoMem

3.1 研究问题

总 RQ:配备原生持久记忆的 coding harness,在同一真实仓库的长期演化任务流上,能否"越用越强"而不退化?收益、损伤与退化各自可归因到记忆机制的哪一环?

分解为五个子问题,横跨三个 track:

  • RQ1(学习,Lifelong track):跨会话经验积累带来的成功率/效率增益曲线是什么形状?哪类记忆内容(环境坑/用户偏好/仓库惯例/工作流)贡献最大?
  • RQ2(机制,Memory track):agent 自写记忆的操作级质量——写入 precision/recall(对照人工标注的"值得记住集合")、放置正确率(user/repo/path 三层 scope)、compaction 后存活率、离线固结前后的卫生与损伤——各是多少?
  • RQ3(保持,Retention track):harness 记忆状态每次更新(append/rewrite/merge/delete/compact)后,历史成功任务的回归率(URR)是多少?回归是否局域(与更新内容的语义距离相关)?
  • RQ4(漂移,Drift 探针,跨 track):仓库演化到 v+1 后,v 时代沉淀的记忆多久失效、造成多大危害、多少任务后被自我纠正?——这是"记忆与仓库协同演化"维度,deep_C6 核实全场无人做。
  • RQ5(干扰与效率):项目 A 的记忆对项目 B 是助益还是污染(跨项目 backward interference)?全部结果在 token/延迟预算约束下按 LAFS 式前沿报告。

3.2 贡献声明(投稿时的 claim 草案)

  1. 首个以 harness 原生记忆机制为受控变量的 coding agent 基准:记忆条件矩阵(无记忆/只读指令文件/auto-memory/auto-memory+定期固结/外挂 MCP 记忆层)× 放置扰动 × 强制 compaction 事件,多 harness(Claude Code / OpenHands / Codex CLI)执行以回应 scaffold-effect 批评;
  2. 首个建立在 live 去污染管线上的记忆基准:全部任务取自各被测模型 cutoff 之后创建的 issue(SWE-rebench 日期标记协议),月度滚动,同时以注入层(合成不可推断事实+可执行 oracle)保证冻结版可复现——正面解决"记忆序列要求长期稳定 vs live 源要求刷新"的矛盾;
  3. 首个 学习-机制-保持三 track 统一协议与配套指标栈:成功率斜率/FT/BWT/复用率(Lifelong)、写入-放置-固结操作级质量(Memory)、URR/Retention@t/locality 曲线(Retention)、过期记忆危害率与纠正延迟(Drift);
  4. 公开 retention 回归集构建工具链(历史成功轨迹回放 + 更新反推探针 + 语义等价扰动)及其统计功效分析——"检出 5pp 净回归需 150–200 配对用例"这类规模-功效曲线本身即方法学贡献;
  5. 实证副产品:现有 harness 记忆机制在真实演化仓库上的净收益何时为正——库内证据(AGENTbench 的 LLM 生成 context 文件负收益、MemTrace 的 61.9→75.5% 有用率伴随 ~20% 坏率、SWE-ContextBench 的自由检索≈零增益)暗示答案可能反直觉,这对 D&B 论文是加分叙事。

会话与记忆协议(基准的机制核心)

每任务一个全新会话(fresh context),仓库 checkout 到该任务对应的真实历史状态;唯一跨任务通道是 harness 持久记忆目录(CLAUDE.md/MEMORY.md/skills/ 或外挂记忆系统),每次记忆变更 git 提交留痕——记忆变更历史本身成为评测产物,直接供 Retention track 以"单次 harness diff"为被测单元做回归归因,也支持 Memory track 的固结正确性对照标注。这一设计把 A5 的机制评测、C6 的序列协议与 D1 的更新级归因焊接在同一份数据上,是三题合并在工程上成立的关键。

Retention track 协议(D1 创新点的落地)

  • 回归用例三来源:历史成功轨迹回放(任务输入+环境快照+可执行验收判据);更新反推探针——对每条被更新的记忆工件自动生成"该工件应支配的行为"探针(RippleEdits 范式移植),使回归集随记忆库增长;语义等价扰动区分真回归与 prompt 敏感性噪声。
  • 统计协议:每用例 k=3–5 次重复取多数票,集合级配对差检验(McNemar/paired-t),任务按族分组用 clustered SE(依 Anthropic《Adding Error Bars to Evals》);检出 5pp 净回归需约 150–200 配对用例——HCL 的 80 anchors/task 只能检出 ~10pp 级回归,这一功效分析结论本身可写入论文。
  • 成本控制:变更感知的切片优先级(CASPER 范式):按更新工件与用例的语义关联度排序,预算内优先跑高风险切片。

四、选题二立项论证:HarnessAblate

4.1 研究问题

总 RQ:在固定进化算法与预算下,单独开放 coding harness 的每一类可编辑面自我进化,各自的收益与风险是多少?是否存在"最小充分集"——组合收益接近全开放而风险显著更低的面子集?
  • RQ1(双轴画像):六类面(system prompt / 长期记忆 / skills / 工具定义 / workflow / 代码本体)逐一开放的收益(held-out 解决率 Δ、步数/成本 Δ)与风险(held-out 回归率、安全探针失败率、膨胀度、可逆性)各是多少?
  • RQ2(最小充分集):是否存在面子集,组合收益 ≈ 全开放,而风险显著低于全开放(尤其低于全代码库开放)?
  • RQ3(调节变量):收益/风险比如何随基座模型能力与任务域(regime)变化?——直接对话 Harness Updating ≠ Benefit 的非单调性发现与 Yu & Desell 的 regime 交互。

4.2 贡献声明

  1. 首个前瞻性(进化只被允许触碰指定面,文件级 ACL 强制)、跨六面、固定算法与预算的 harness 可编辑面交叉消融——区别于 AHE 的事后换入归因,回答的是部署者真正的问题"该开放什么";
  2. 首次把风险轴做成一等公民:回归率、Misevolution 式安全探针、膨胀曲线、随机回滚可逆性四项与收益并列报告——现有全部证据只测收益;
  3. "最小充分集"结论与开放决策查找表(面 × 模型能力 × 任务域),为 harness 自进化的产品化提供第一份受控证据;
  4. 通路证据协议(借鉴 PAST-Bench):trace 级验证增益是否真经过被开放面,排除旁路效应。
