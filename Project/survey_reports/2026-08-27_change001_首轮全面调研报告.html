摘要：本轮调研的八条核心判断

  1. 竞争主战场已从模型转移到 harness。前沿模型在 SWE-bench Verified 上收敛到 1pp 以内，而 harness/scaffold 变动可摆动 20pp 以上（HAL 报告跨 scaffold 差距 34–48pp；Claw-SWE-Bench 中模型选择影响 29.4pp、harness 选择影响 27.4pp）。"报告成绩必须披露 harness"正成为评测新规范（Binding Constraint Thesis）。
  2. coding harness 的记忆载体全面收敛于明文 Markdown 文件，压倒向量库。Claude Code、Codex、Cursor、Gemini CLI、OpenHands、OpenClaw 无一采用向量库作为主记忆——分层指令文件（CLAUDE.md / AGENTS.md）+ 按需披露的 skills + 可选 auto memory 成为三件套。原因：代码场景要求记忆可审计、可版本控制、可随仓库分发。
  3. 经验抽象取代轨迹存储。"存储 → 反思 → 经验"三段论成为共识：朴素经验回放已被 LifelongAgentBench 证伪为弱基线；ReasoningBank/ACE 证明失败经验蒸馏与成功同等重要；抽象层级越高（轨迹 → 案例 → 工作流 → 技能 → 元技能），迁移性越强。
  4. "离线固结（consolidation）"成为学术与工业罕见同步的议题。2026 年 OpenAI Dreaming V3 与 Claude Dreaming 双双落地"睡眠期整理记忆"进程；分歧只在固结目标——明文文件（Anthropic）、持续重写的合成状态（OpenAI）还是模型参数（研究前沿）。
  5. 自进化研究的重心从"设计 agent"移到"进化 harness"。2024 的 ADAS/AFlow 搜索工作流，2025 的 DGM/SICA 改整个 agent 代码库，2026 的 Self-Harness/AHE/Meta-Harness 把 harness 组件化为显式可编辑面并配回归验证。关键新认知：harness 更新能力在 9B 到 Opus 级模型间近乎持平，收益能力才是瓶颈——"小模型进化、大模型执行"的廉价配方成为可能。
  6. 富文本反馈优于标量奖励，而 harness 恰是文本反馈的富矿。GEPA 以富文本反馈比 GRPO（RL）高最多 +20% 且 rollout 少 35 倍；coding harness 天然盛产编译错误、测试日志、退出码等可验证信号，可绕开"LLM 自判成败"这一最大质量风险。
  7. harness 已被确立为继模型权重之后的第二持续学习载体，但其"遗忘"无人防护。HCL（2026-08）正式提出 harness-level forgetting：更新任一 harness 组件可能在模型不动的情况下破坏既有行为；非参数系统的遗忘只是换了形态（context collapse、检索退化、无关经验干扰），且除 HCL 外没有任何生产 harness 做保持性检查。
  8. 安全是全领域最大冷水：进化通路即攻击面。Misevolution 实证：记忆进化的 coding agent 经几轮进化后拒绝率下降 45–55%，工具进化 agent 在 76%+ 案例中生成或复用带漏洞工具，顶级模型无一幸免；记忆污染等于持久化提示注入，固结管线可把单次攻击放大为永久损伤。

分支 A：Agent 记忆

领域图景

该领域从 2023 年 Generative Agents（memory stream + 检索 + 反思）与 MemGPT（分层记忆 + agent 自主管理）两大奠基工作出发，沿四个正交维度展开：载体形态（上下文内 KV / 外部明文 / 参数化）、操作环节（写入 → 管理 → 读取，即"提取/管理/存储/检索"四阶段）、内容类型（用户画像 / 情景 / 语义 / 程序性记忆）与管理者（固定管线 / agent 自管理 / RL 或测试时训练的学习型管理）。外部明文路线内部又经历了"扁平向量库 → 分层树（MemTree）→ 知识图谱（HippoRAG）→ 时间图谱（Zep/Graphiti 的双时间线与边失效）→ 文件系统（Claude Code）"的结构演化。2025 年起"记忆操作系统"叙事（MemOS 的 MemCube 统一明文/激活/参数三形态、MIRIX 的六类记忆分区）与学习型记忆管理（MemAgent 用 RL 学"记什么忘什么"、Titans 的测试时神经记忆）并行兴起。

关键结论

  • 长上下文 vs 外部记忆之争落幕于"互补 + 效率一等指标"：Mem0 实测全上下文准确率上限更高但 p95 延迟差 91%；HippoRAG 2 论证结构化记忆在关联/时间任务上反超长上下文；新基准（BEAM、LongMemEval-V2）将 token 足迹与延迟纳入排行（LAFS 类联合指标）。
  • 评测重心从"对话回忆"迁移到"agent 经验"：LoCoMo/DMR 类问答基准已趋饱和且被刷榜；MemoryArena 度量"记忆→行动"转化率，LongMemEval-V2（环境陷阱、工作流知识、前提感知等五能力，最大 115M token 历史）几乎是为 harness 记忆量身定制的评测框架。
  • 检索噪声有毒：Harness the Memory（2026）发现 agentic 任务中错误检索比不检索更糟，而把经验蒸馏成紧凑技能包的"精炼族"基质质量随规模增长且读取成本恒定——对 coding harness 的记忆设计有直接指导意义。
  • 评测信任危机：厂商自报与独立复测差距悬殊（某记忆产品自报 LongMemEval 93.4%，独立复测 OSS 版仅 32.4%，低于无记忆基线 57.6%），催生 AMB、Bench'd 等中立评测平台。
  • 冲突消解与知识更新是所有基准上最弱的能力项（MemoryAgentBench 结论：现有系统没有一个四项全优）。

分支 B：Agent 自进化

领域图景

自进化领域可用三个正交轴定位任何工作：进化对象（artifact 输出物 → harness 的 prompt/记忆/工具/技能/工作流/代码 → 模型权重）、进化时机（任务内 / 跨任务 / 跨 agent）、进化信号（标量奖励 vs 富文本反馈；单体自改 vs 群体进化）。谱系上：2023 年 Reflexion/Self-Refine 确立"以文本代替梯度"的最小范式，Voyager 确立"技能=经过验证的代码+可检索描述"，STOP 首次实验"改进改进器"并警示弱模型上递归改进反而退化；2024 年 ADAS 确立"agent 设计空间=代码空间，用 LLM 搜索之"，AFlow 用 MCTS 使搜索效率大增（比 ADAS +19.5%）；2025 年 DGM 验证"冻结模型 + 进化 harness 代码"配方（SWE-bench Verified 20.0%→50.0%），HGM 以谱系潜力（CMP）替代表型分数做选择信号，AlphaEvolve 在 artifact 层做出真实科学发现（56 年来首次改进 Strassen 4×4 复矩阵乘法）；2026 年 Self-Harness/AHE/Meta-Harness/MCE 把 harness 本身组件化为显式可编辑面，配可观测性与回归验证。prompt 子层则有 DSPy（编译式优化标准框架）→ TextGrad（文本梯度，登上 Nature）→ GEPA（反思进化，ICLR 2026 oral，当前 SOTA）一条清晰的演进线。

关键结论

  • harness 设计本质上是 model-specific 的，应由模型自己学（Self-Harness 发现学到的 harness 机制模型特异）——直接论证"每个 harness 配套自进化层"的必要性。
  • 能力解耦的新认知：Lin et al. 2026 表明从 Qwen3.5-9B 到 Claude Opus 4.6，harness 更新能力基本持平，收益能力才非单调且中档模型获益最大。结合 ShinkaEvolve 的样本效率（约 150 样本达 SOTA，AlphaEvolve 需数千）与 GEPA 的 20–100 样本需求，"单机夜间跑私有 harness 自进化"已经可行。
  • AHE 的消融定位收益主要来自 tools、middleware 与长期记忆，而非 system prompt——为可编辑面的优先级排序提供了首个证据。
  • 安全冷水（Misevolution）：记忆进化致拒绝率下降 45–55%、工具进化 76%+ 案例带漏洞、近 84% 无法识别恶意外部工具；共识性防御是评估器与权限置于进化环外且只读、held-in/held-out 双重回归、沙箱+谱系可追溯。
  • 争议未决：纯 scaffolding 自改进有无天花板（SICA 明言有、DGM 认为开放式探索可持续）；弱评估器（研究品味、repo 长期健康）下如何构造进化信号几乎空白（Lilian Weng 七挑战之首）。

分支 C：Agent 持续学习

领域图景

本分支回答"LLM agent 如何在不断执行任务中变强而不忘掉已会的东西"。实现手段分三条轴：参数轴（持续预训练/微调/测试时训练 TTT）、上下文轴（维护一份持续编辑的 playbook：Dynamic Cheatsheet → ACE）、外部记忆轴（按抽象层级递增：原始轨迹回放 → 案例 Memento → 因果模式 CLIN → 工作流 AWM → 策略记忆 ReasoningBank → 可执行技能 Voyager/SkillWeaver → 程序性脚本 Memp → 元技能 MemSkill）。2023–2026 的主线是"从存储轨迹到反思轨迹再到抽象经验"，手段上从参数更新全面转向训练无关的上下文与外部记忆演化；2026 年参数化 TTT 回潮，三轴正合流为"半参数"设计（外部库承担事实与程序知识、偶发参数更新承担能力内化）。

关键结论

  • 朴素经验回放被证伪：LifelongAgentBench 系统实验表明把历史成功轨迹塞回上下文收益有限甚至有害（无关信息干扰+上下文约束）；StreamBench 则表明只回放"自我生成且被证实正确"的例子就是极强的廉价基线——关键在筛选而非量。
  • 失败经验入库成为新共识：ReasoningBank/ACE 证明从失败中蒸馏与成功同等重要，纯"成功例程库"已过时；MaTTS 进一步确立"经验驱动的扩展"为继模型/数据/测试算力之后的新扩展维度。
  • 非参数系统的"遗忘"换了形态：context collapse（整体重写丢信息）、无关经验干扰、context rot 构成新的稳定性-可塑性议程；Panini（2026）给出了 agent 场景选非参数路线的最完整论证，同时 CL 社区已把"agent 外部记忆"正式收编为遗忘缓解的一等公民路线（半参数方法）。
  • 技能生命周期工程化：2026 年出现三篇技能综述与 Skills Bench 系基准，验证/准入/修剪/治理成为标准阶段；SKILL.md 等 harness 原生格式被学术界正式收编——工业实践正在反哺学术议程。
  • harness 相对学术系统有两大天然优势：(a) 执行环境提供客观成败信号（编译、测试、退出码），绕开 LLM 自判这一最大质量风险；(b) git 免费提供版本化、审查与回滚，正是学术界呼吁的治理层。"harness 原生持续学习"具备超越现有论文系统的条件。

分支 D：Harness 本体最新动态（2025–2026.8）

领域图景

2025–2026 年几乎所有主流 harness 收敛到"分层 markdown 指令文件 + 按需披露的 skills + 可选 auto memory"三件套；AGENTS.md（指令，60,000+ 开源项目采用）、MCP（工具）、Agent Skills（技能）形成三大开放标准栈，记忆是唯一还没有开放标准的一层。一年之内完成了从"手写指令文件"到"agent 自写记忆默认开启"的范式切换（Claude Code auto memory 默认开 → OpenHands SDK 持久记忆 → Gemini 实验性 auto memory）。学术侧，harness 被确立为独立研究对象：Binding Constraint Thesis（长程任务性能方差更多由 harness 而非模型决定）、Harness-Bench（模型越强对 harness 越不敏感，harness 是能力的放大器/瓶颈）、HCL（harness-level forgetting 的正式定义）、SIGIL（prose skill 执行保真度仅 56%，编译成类型化 harness 后稳定 86%）。

关键结论

  • harness 差异被系统量化：SWE-bench Pro 上六个前沿模型在统一 scaffold 下仅差 4.9pp，而固定模型换 harness 差 9.5pp；Harness-Bench 最高与最低 harness 聚合差 23.8pp；Claw-SWE-Bench 同一底座下极简适配器 19.1% vs 完整适配器 73.4%。
  • 写入策略无理论：何时记、记什么、如何合并去重，各家全靠 prompt 里的"纪律条款"（OpenHands 写入规范、Claude 的 200 行索引约束），没有可度量的记忆价值函数。
  • 记忆的 token 经济学之争：OpenClaw 默认全量注入 workspace 文件成本高昂，催生 SoulClaw（三级分层加载省 60%）、MemClaw（三层语义记忆+向量检索，声称省 95%）——"全量注入 vs 分层按需检索"是 2026 年记忆工程的活案例。
  • 沉淀止步于文本是下一个瓶颈：SIGIL 证明 prose 沉淀执行保真度仅 56%（且产物能骗过输出检查），编译式/程序式沉淀刚起步；memory（事实）→ rule（约束）→ skill（流程）→ 编译 harness 构成沉淀强度光谱，"何种经验沉淀到哪一层"没有任何理论。
  • 模型-harness 协同设计开始：GPT-5-codex 针对 Codex CLI 后训练、MiniMax 针对 OpenClaw scaffold 自进化训练；mini-swe-agent 上 Gemini 3 Pro 达 SWE-bench Verified 74%，说明前沿模型已内化大部分 harness 功能——harness 学习成果可能被下一代模型吸收而贬值。

底稿：Project/survey/branch_D_harness动态.md

跨分支综合

一、领域收敛趋势（四分支交叉验证）

  • 明文文件式记忆压倒向量库（A + D 一致）：coding harness 无一采用向量库作主记忆；文件式记忆可审计、可 git diff/review/回滚、可随仓库分发，git 免费提供了学术界呼吁的治理层。代价是 token 成本，第二代方案（索引+按需加载、渐进披露）正在解决。
  • 重心从设计 agent 转向进化 harness（B + D 一致）：领域词汇已从"agentic system"收敛到"harness"（Lilian Weng 2026-07 博客定名）；LangChain 的三层学习分类（模型层/harness 层/context 层）与 HCL 的正式问题定义共同把 harness 状态确立为第二学习对象。
  • 经验抽象取代轨迹存储（A + C 一致）：Harness the Memory 的"精炼族基质"与 C 分支的"storage → reflection → experience"三段论互相印证；抽象层级（轨迹→案例→工作流→技能→元技能）成为组织该方向的主坐标。
  • 固结通道成为交汇点（A + B + C 汇流）：Xinming Tu 的固化通路（临时 artifact → 可复用 harness 逻辑 → 模型权重）、Claude/OpenAI 的 Dreaming 产品、consolidation 立场文与半参数持续学习在同一个问题上会师——何时固结、固结什么、固结到哪一层。
  • 评测改革同步展开（A + C + D 一致）：效率成为一等指标（LAFS/MemScore）、流式协议取代静态集合（StreamBench → LifelongAgentBench）、harness 披露与 locked-harness 协议、第三方中立复测平台（AMB、Bench'd）。

二、共性缺口

缺口证据来源现状
记忆写入策略无理论（何时写、写什么粒度、如何合并）D（各家靠 prompt 纪律条款）、C（Memp 初步触及无定论）纯 prompt 工程，无可度量的记忆价值函数
harness-level forgetting 无人防护D（HCL 刚定义）、C（context collapse/检索退化）没有任何生产 harness 做 retention 回归检查
冲突消解与知识更新A（MemoryAgentBench：普遍最弱项）、C（新旧经验仲裁短板）无好解；跨会话实体对齐同样空白
经验质量与污染（自判错误自我强化）C（LLM-as-judge 偏差未量化）、B（reward hacking）缺可靠的验证、置信标注与溯源机制
缺面向 coding harness 的记忆/lifelong 基准A（明确论文机会）、C（SWE 任务流空白）、D（跨会话学习收益只有厂商内部数字）完全空白，评测先行的机会窗口
沉淀止步于文本D（SIGIL：prose 保真度 56%）编译式/程序式沉淀刚起步
跨工具记忆孤岛A + D（Cursor/Claude/Devin 互不相通）MCP memory server 是唯一在野方案，无标准

三、安全风险

进化通路即攻击面（四分支共同指向）：
  • 记忆污染 = 持久化提示注入：ChatGPT 注入式记忆已被验证为攻击路径（Tenable 等）；OpenHands 官方明确警告记忆文件可能携带 prompt injection，须当作未验证提示。
  • 安全对齐随进化衰减：Misevolution 实证记忆进化后拒绝率下降 45–55%，工具进化 76%+ 案例带漏洞，Gemini-2.5-Pro/GPT-4o/Claude-4 无一幸免；微调后安全护栏退化已被建模为灾难性遗忘的特例。
  • 固结管线的放大风险：离线固结可把单次攻击放大为永久损伤；溯源、版本化、回滚机制刚起步。
  • 共识性防御设计：评估器与权限层置于进化环外且只读（AHE）、held-in/held-out 双重回归验证（Self-Harness）、沙箱+谱系档案可追溯（DGM）、异步 overseer 可叫停（SICA）、写入门禁与人工审核（Devin/Cursor 的晋升路径）。harness 内记忆全部落盘为项目文件，可用 hooks/review 门禁审计写入——是 harness 场景的天然安全优势。

排序候选选题理由风险
1 C-6 + A-5（建议合并） 面向 coding harness 的 lifelong 记忆基准：SWE 任务流 + 技能依赖图 + 流式协议，同时评"跨会话记忆"与"持续学习曲线" 三个分支独立确认此空白（A：无 coding harness 记忆基准；C：SWE 任务流 lifelong 基准空白；D：跨会话学习收益只有厂商内部数字如 Anthropic +39%）。评测先行契合领域改革潮流；LifelongAgentBench 的技能依赖设计与 LongMemEval-V2 的五能力框架提供现成参照；coding 场景有客观成败信号，天然规避 LLM 自判偏差；本项目"多标注多验证"的资源假设正中基准建设的需求。产出还能直接服务后续所有实验。 基准类论文竞争者可能同期出现（LongMemEval-V2 已很接近），需靠"任务间依赖 + 流式协议 + 成本曲线"的组合差异化。
2 D-1 harness-level forgetting 的量化与 retention 回归集：度量"更新记忆/skills 导致既有行为回归"，构建守护机制 HCL（2026-08）刚提出概念，其 Continual Evaluator 依赖的"历史正确行为集"实践中无人维护——概念已立、防护空白，时间窗口极佳；与排序 1 的基准工作天然衔接（retention 集可复用基准任务）；工程可落地（git + hooks 现成）。 需要足够规模的回归集才有统计效力；与 HCL 团队后续工作存在撞车可能。
3 B-1 harness 可编辑面的最小充分集：对 AHE 的 7 组件逐一消融，回答"哪些面开放进化收益/风险比最优" AHE 已给出初步信号（收益主要来自 tools/middleware/长期记忆而非 system prompt），但系统性逐组件消融缺失；结论对所有 harness 自进化工作有指导价值；Misevolution 四通路审计可同框完成，一石二鸟（顺带覆盖 B-4）。 算力消耗大（factorial 消融），且结论可能是 model-specific 的（Self-Harness 的发现），需多模型验证。
4 B-3 弱评估器下的自进化：无快速 verifier 任务（repo 长期健康、可维护性）的进化信号构造 Lilian Weng 列为七挑战之首、几乎空白，理论价值最高；本项目标注人员资源可构造人工评估信号。 最难：无客观信号意味着评测本身就是未解问题，周期长、不确定性高。建议作为长线储备而非首发选题。
综合建议：以"评测先行"为第一原则——先做 C-6+A-5 合并的 coding harness lifelong 记忆基准（兼具发表价值与项目基础设施价值），D-1 的 retention 回归集作为其自然延伸构成第二篇；B-1 消融研究在基准就绪后展开；B-3 作为长线方向持续跟踪。该路线图同时覆盖了 CLAUDE.md 使命中的三个目标：汇集先进实践（wiki）、指导现实设计（基准+守护机制可直接落地本项目 harness）、产出顶会论文。
