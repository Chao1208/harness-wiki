# 可编辑面（Editable Surfaces of a Harness）

> **一句话结论**：harness 的可编辑面已形成清晰谱系——**单面**（ACE/CODESKILL 只改 prompt 或 skills）→ **有界多面**（Self-Harness 声明式配置点）→ **显式组件全集**（AHE 七组件文件级暴露）→ **全代码库**（DGM/Meta-Harness）；"完全没有组件消融证据"的旧判断**不成立**（AHE 换入消融、Yu & Desell 工具面交叉消融、CODESKILL 生命周期消融、PAST-Bench 配对对照均已存在），但证据**碎片化且几乎只测收益不测风险**；真空白 = 同一 harness 上固定进化算法与预算、对六类面做"开放哪个面"的**前瞻性交叉消融**并量化收益/风险双轴——寻找"最小充分集"（组合收益接近全开放而风险显著更低）。

## 六类可编辑面与粒度谱系

六类面：**system prompt / 长期记忆 / skills / 工具定义 / workflow（hooks+循环策略）/ 代码本体**。综述《Self-Evolving Coding Agents》的六类进化目标分类（framework、experience & repo memory、skill & tool、model、workflow & topology、environment & context）与此正交。

| 粒度档 | 代表系统 | 开放范围 | 安全机制 |
|---|---|---|---|
| 单面 | ACE/GEPA（prompt）、CODESKILL/SkillClaw（skills）、AWM（workflow） | 一类文本工件 | 基本无 |
| 有界多面 | Self-Harness | harness 定义文件中声明的配置点 | 回归测试门禁，只能改声明过的面 |
| 显式组件全集 | **AHE**（七组件：system prompt、tool description/implementation、middleware、skill、sub-agent 配置、长期记忆） | 文件级暴露 | 可回滚；编辑须附可验证预测 |
| 全代码库 | DGM、SICA、Meta-Harness、LLM-as-Code | 整个 harness 代码 | sandbox/archive，无组件级护栏 |

产品对照：Claude Code 开放的是配置面（CLAUDE.md/memory/skills/hooks/MCP），核心循环闭源不可改，安全机制是权限系统+hooks 审批。

## 逐面消融证据强度（截至 2026-08）

| 面 | 收益证据 | 风险证据 | 强度 |
|---|---|---|---|
| 工具定义/实现 | AHE Table 3 换入增益显著；Yu & Desell 工具面×任务域×agent 设计交叉消融 | Misevolution：工具进化可引入漏洞 | **较强**（唯一有双向证据） |
| 长期记忆/经验 | AHE 换入有增益；PAST-Bench 开/关配对对照（7 模型×4 框架，提升真实但按能力维不均匀） | Misevolution：记忆污染→安全衰减 | **较强** |
| skills | CODESKILL 生命周期逐级消融（evolution +2.1 通过率；maintenance 牺牲 ~2% 换 bank 减半） | 无 maintenance 时 skill bank 从 676 膨胀到 1252 | 中等（有面内消融，缺跨面对照） |
| system prompt | **AHE：单独换入进化后的 system prompt 反而回退**——目前唯一"某面单独开放为负收益"的直接证据 | 失败教训无限追加 → harness 膨胀 | 中等偏弱 |
| workflow/中间件 | AHE middleware 换入有增益；AWM 归纳有效 | 路由条件堆积、耦合上升 | 弱 |
| 代码本体 | DGM/SICA 证明全代码进化整体有效，但**无人对比"全代码 vs 受限面"同预算差异** | DGM 已报告 reward hacking 式行为 | 弱（只有整体循环证据） |

补充证据：Ben Sghaier et al. 观察性纵向研究定位 LLM Provider 与 Context Management 组件回归风险最高（但混杂无法归因）；Harness Updating ≠ Benefit 发现更新能力与受益能力解耦、受益随模型能力非单调（retention/消融结论须绑定执行模型）；综述明确指出产品级进化能力普遍"describes the mechanism without reporting an ablation"，harness 膨胀与可逆性是开放问题。

## 立项方向（据 deep_B1 §4）

**RQ1**：固定进化算法与预算下，单独开放每类面自进化，各自的收益（成功率/成本）与风险（held-out 回归率、安全衰减、膨胀度、可逆性）是多少？**RQ2**：是否存在最小充分集？**RQ3**：收益/风险比如何随模型能力与任务域变化？

设计要点：双 harness 臂（开源六面全开 + Claude Code 配置面子集验证外推）；统一 Self-Harness 式进化循环、文件级 ACL 强制只写开放面；9 条件（C0 冻结基线、C1-C6 单面、C7 全开、C8 自适应最小充分集）×3 种子；SWE-bench Verified（repo 切分 train/held-out）+ Terminal-Bench 2 域外冻结集；风险四件套（回归率/安全探针/膨胀曲线/回滚恢复度）+ PAST-Bench 式通路证据（trace 级验证增益真经过被开放面）。成本粗估 ~27,000 次 agent 运行、API $10k-40k。

与最像竞品的差异：AHE Table 3 是**事后换入归因**（哪部分变了），我们做**前瞻性开放消融**（开放什么）——且加风险轴、固定预算、多 harness。主要风险：结果可能与 AHE 排序一致而"无聊"（对策：风险轴与最小充分集做成一等公民）；自进化实验 run-to-run 方差大；AHE 团队是最可能的抢发者，宜快速立项。
