## 一、课题一句话

在同一 coding harness 上、**固定进化算法与预算**,对六类可编辑面(system prompt / 长期记忆 / skills / 工具定义 / workflow / 代码本体)做"开放哪个面自我进化"的**前瞻性交叉消融**,同时量化**收益**(成功率/成本)与**风险**(回归率/安全衰减/膨胀/可逆性),寻找"最小充分集"。目标会议 **ICML 2027**(备选 NeurIPS 2027 主会)。

### 三个研究问题

- **RQ1**:单独开放每一类面,各自的收益与风险是多少?
- **RQ2**:是否存在最小充分集——组合收益接近全开放、风险显著更低?
- **RQ3**:收益/风险比如何随基座模型能力与任务域变化?

### 空白点判定(change-002 核实结论)

"完全没有组件消融证据"**不成立**——已有五处碎片证据(见下表);但**跨面 × 收益/风险双轴 × 固定预算的前瞻性消融不存在**,此为本课题立足点。注意措辞:我们不是"首个组件消融",而是"首个跨面、双轴、预算受控的可编辑面消融基准"。

## 二、核心锚点论文:AHE

- **库内 id**:`2026-lin-agentic-harness-engineering`(PDF:`raw/papers/2026-lin-agentic-harness-engineering.pdf`)
- **wiki 称呼**:AHE / Agentic Harness Engineering,详见 [wiki/可编辑面.md](../../wiki/可编辑面.md) 与 [wiki/agent自进化.md](../../wiki/agent自进化.md)
- 标题:Agentic Harness Engineering: Observability-Driven Automatic Evolution of Coding-Agent Harnesses(Lin et al., 复旦+北大+奇绩智峰, arXiv 2604.25850)
- **代码已开源**(2026-08-30 联网核实,见 `Clipping/2026-08-30_github_AHE与SelfHarness代码发布核实.md`):
  https://github.com/china-qijizhifeng/agentic-harness-engineering (MIT, 860+ stars, 活跃维护, 曾登 Terminal-Bench 2.0 榜第 3)
- 关键结果:10 轮进化把 GPT-5.4 在 TB2 的 pass@1 从 69.7% 提到 77.0%;**Table 3 单组件换入消融**:memory +5.6 / tool +3.3 / middleware +2.2 / **system prompt 单独换入 −2.3(负收益)**;组件交互非加性(三正向单面之和 +11.1 > 全开 +7.3)
- 关键超参(论文附录 Table 4):10 轮 × 89 题 × k=2 rollouts,并发 96,E2B 沙箱,单 campaign 约 32 小时
- **它与我们的本质差异**:AHE Table 3 是*事后换入归因*(进化完了再拆开看哪部分有用);我们做*前瞻性开放消融*(进化前就限制只能改某面)——回答"该开放什么"而非"哪部分变了"。**AHE 团队是最可能的抢发者,时间窗 4-6 周实验期,尽快动手。**

## 四、实验设计与预算(完整版见底稿第 4 节)

- 平台:开源臂(**建议直接基于 AHE 开源仓库改造**,六面文件级 ACL)+ Claude Code 配置面臂
- 条件:C0 冻结基线 / C1-C6 单面 / C7 全开 / C8 最小充分集候选;每条件 15 轮 × 3 seeds
- 任务:SWE-bench Verified 100 题(60 train / 40 held-out,按 repo 切分)+ Terminal-Bench 2 域外
- 风险度量:held-out 回归率、Misevolution 式安全探针、膨胀曲线、回滚恢复度、PAST-Bench 式通路证据
- 预算:全量约 27,000 次运行 / $15k-40k(中值 $25k);降本路径:开源模型跑全矩阵 + 闭源只复现关键条件 → ~$10k
- **里程碑 M1(建议)**:复现 AHE——先冒烟(1-2 轮×20 题×k=1,数百美元),再核心复现 10 轮 campaign($3k-6k,约 1 周),复现平台即实验床、其 Table 3 即对照

## 五、主要风险(诚实清单)

1. 结果与 AHE 排序一致则"不惊喜" → 风险轴与最小充分集必须做成一等公民
2. 自进化 run 间方差大,3 seeds 可能不够 → 预实验估方差,必要时配对检验
3. 面间交互被单面消融低估 → C8 + leave-one-out 部分覆盖,2^6 全因子不可负担,明说
4. Claude Code 闭源臂外推性质疑 → 引 Dive into Claude Code 论证组件同构
5. AHE 团队抢发 → 尽早挂 arXiv 占位;实验窗 4-6 周
6. 模型版本漂移 → 锁 snapshot
